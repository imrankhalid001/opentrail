# UI/UX Craftsmanship Principles ✨

1. **Clarity Over Clutter**: Prioritize high-value travel intelligence (weather, route, landmark summary) over dense text blocks.
2. **Predictable Feedback**: Every touch interaction must yield immediate visual or tactile feedback (ink ripples, button scale, loading shimmers).
3. **Graceful Degradation**: Error states (`AppErrorState`) and empty states (`AppEmptyState`) must provide actionable recovery options (e.g., "Retry connection" or "Explore suggested destinations").
4. **Consistent Typography Hierarchy**: Use M3 type scale without adding arbitrary font sizes in widgets.
