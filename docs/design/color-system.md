# Color System 🎨

OpenTrail uses an adventurous, nature-inspired Material 3 color palette.

## Core Palette Tokens

| Token Name | Light Mode Hex | Dark Mode Hex | Semantic Role |
| :--- | :--- | :--- | :--- |
| `primary` | `#006A60` (Teal) | `#53DBC9` | Main brand color, active states, key CTAs |
| `secondary` | `#4A635F` | `#B1CCC6` | Secondary actions, chip selections, badges |
| `tertiary` | `#4B607A` (Deep Sky) | `#B2C8E8` | Weather highlights, map overlays |
| `error` | `#BA1A1A` | `#FFB4AB` | Error messages, destructive actions |
| `surface` | `#FAFDFC` | `#101413` | Screen background, card surface |
| `surfaceContainer` | `#F0F4F3` | `#1D2120` | Elevated card backgrounds, search bars |
| `onSurface` | `#191C1C` | `#E1E3E2` | Primary text and icons |

---

## Dynamic Dark Theme
OpenTrail automatically transitions all surfaces, cards, and text styles based on system dark mode preferences or manual user selection.
