# Typography Scale 🔤

OpenTrail uses the official **Material Design 3 Typography Scale** configured with clear hierarchical fallback fonts (`Roboto`, `SF Pro Text`, or system native fonts).

## Type Scale Specification

| Style Token | Font Size | Weight | Line Height | Usage |
| :--- | :--- | :--- | :--- | :--- |
| `displayLarge` | 57 pt | Regular (400) | 64 pt | Hero destination title |
| `displayMedium` | 45 pt | Regular (400) | 52 pt | Splash screen typography |
| `headlineLarge` | 32 pt | SemiBold (600) | 40 pt | Screen main headers |
| `headlineMedium` | 28 pt | SemiBold (600) | 36 pt | Section headers (`AppSectionHeader`) |
| `titleLarge` | 22 pt | Medium (500) | 28 pt | Card titles (`AppCard`, `AppTripCard`) |
| `bodyLarge` | 16 pt | Regular (400) | 24 pt | Main paragraph body text |
| `bodyMedium` | 14 pt | Regular (400) | 20 pt | Subtitle text, list item body |
| `labelLarge` | 14 pt | Medium (500) | 20 pt | Button text (`AppButton`) |
| `labelSmall` | 11 pt | Medium (500) | 16 pt | Chips, badges, caption labels |
