# Data Models & Serialization Strategy 📦

OpenTrail strictly enforces **Immutability** and **Value Equality** for all state and domain models using **Freezed (`freezed`)** and **JSON Annotation (`json_annotation`)**.

---

## 1. Solution Selection & Evaluation

### Why Freezed?
- **Immutability Guarantee**: All generated properties are `final`, preventing unintended side-effect mutations across widget builds.
- **Deep Value Equality**: Automatically overrides `operator ==` and `hashCode` based on field values rather than object memory reference addresses.
- **`copyWith` Pattern**: Provides safe, non-mutating state copy methods for modifying nested properties.
- **Sealed Unions**: Supports exhaustive pattern matching for complex domain states (e.g., UI state unions).
- **Seamless JSON Integration**: Integrates directly with `json_serializable` for automated `fromJson` and `toJson` code generation.

### Alternatives Evaluated

| Tool / Approach | Pros | Cons | Decision |
| :--- | :--- | :--- | :---: |
| **Freezed (`@freezed`)** | Automated value equality, `copyWith`, JSON conversion, sealed unions | Requires `build_runner` generation step | **Selected** |
| **Manual Boilerplate** | Zero dependencies | Verbose; error-prone `copyWith` and `operator ==` implementation | Rejected |
| **Equatable** | Value equality without build_runner | No automatic `copyWith` or JSON serialization code generation | Rejected |
| **BuiltValue** | Strict immutability | Heavy verbose syntax and rigid builder boilerplate | Rejected |

## 2. Multi-Tier Model Layering

OpenTrail cleanly separates models across 3 architectural layers:

```
 [REST API JSON Payload]
           │
           ▼
 [API DTO Models (Data Transfer Objects)]
 (Annotated with @JsonSerializable for Dio parsing)
           │
           ▼ (Mapped via DtoMapper)
 [Domain Entities]
 (Annotated with @freezed; used in ViewModels & UI)
           ▲
           │ (Mapped via DbMapper)
 [Database Models (Drift SQLite DataClasses)]
 (Auto-generated by Drift for local SQLite persistence)
```

### Layer Responsibilities & Model Types

1. **API Models / DTOs (`data/models/`)**:
   - Mirror remote REST API JSON response payloads.
   - Annotated with `@JsonSerializable(explicitToJson: true, fieldRename: FieldRename.snake)`.
2. **Domain Entities (`features/<feature>/domain/` or `data/models/`)**:
   - Pure, clean domain representations used in ViewModels and UI widgets.
   - Annotated with `@freezed`. Expose `copyWith` and `fromJson`/`toJson` factories.
3. **Database Models (`core/database/`)**:
   - Drift SQLite schema table definitions and auto-generated `DataClass` entities.

## 3. Code Examples & Usage Patterns

### Domain Model Example (`Destination`)

```dart
import 'package:freezed_annotation/freezed_annotation.dart';

part 'destination.freezed.dart';
part 'destination.g.dart';

@freezed
class Destination with _$Destination {
  const factory Destination({
    required String id,
    required String name,
    required String country,
    required String countryCode,
    required double latitude,
    required double longitude,
    required String summary,
    @Default(false) bool isFavorite,
  }) = _Destination;

  factory Destination.fromJson(Map<String, dynamic> json) =>
      _$DestinationFromJson(json);
}
```

### Immutability & `copyWith` Usage

```dart
// Creating an immutable instance
const original = Destination(
  id: 'tokyo',
  name: 'Tokyo',
  country: 'Japan',
  countryCode: 'JP',
  latitude: 35.6762,
  longitude: 139.6503,
  summary: 'Capital city of Japan.',
);

// Updating property without mutating original instance
final updated = original.copyWith(isFavorite: true);

assert(original.isFavorite == false);
assert(updated.isFavorite == true);
```
